# UMBC Interactive Campus Map 🗺️

🚀 [Live Demo](https://khushika1805.github.io/3_4_UMBCMAP/)

## 📌 Project Overview

This project is an interactive, searchable campus map for the University of Maryland, Baltimore County (UMBC). Designed with usability and responsiveness in mind, it enables users to locate buildings, parking lots, dining spots, and residence halls with ease. Built as part of a semester-long software project, the application supports intuitive dropdown-based navigation, dynamic filtering, and location-specific details.

---

## ✨ Features

- 🔍 **Search by Category**  
  Easily find UMBC campus resources via categorized dropdowns:
  - Buildings
  - Dining
  - Parking (with permit filtering)
  - Residence Halls

- 📍 **Google Maps Integration**  
  Campus locations are visually represented with clickable markers.

- 🗂️ **Filter by Parking Permit**  
  View parking lots allowed under selected permit types (A–G, Z).

- 💡 **Expandable Sidebar**  
  Sidebar tabs for Search and Route planning. UI adapts to mobile screens.

- 🕶️ **Dark Mode Toggle** *(Coming Soon)*  
  Planned feature for night-friendly viewing.

---

## 🏗️ Technologies Used

- HTML5 & CSS3
- JavaScript (Vanilla)
- Google Maps JavaScript API
- Tailwind-inspired utility classes (customized)
- SweetAlert2 for UI alerts
